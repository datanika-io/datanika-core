# v0.2.1

Notes for `v0.2.1`, tagged 2026-09-17 on `master` `da634df5`. Self-hoster-facing, like
`v0.2.0.md`.

## Breaking

None recorded.

- Two migrations run on start, and both are additive: one changes the default of
  `invitations.status`, the other adds two nullable columns to `runs`. No existing row is rewritten.
- The web framework moves to starlette 1.6.0, still under Reflex 0.8.26.
- The image includes the FreeTDS ODBC driver, which the SQL Server and Synapse destinations load
  through. The build fails if the driver is not registered.
